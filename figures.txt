[7] DIJKSTRA PATHFINDING — TILE WEIGHTS & PASSABILITY
────────────────────────────────────────────────────────────────────────────────
  Weights are decided in TWO places (not per tile-type in GameObjects.h):

  (A) PASSABILITY — GameEngine::buildGrid(who, grid[])
      Location : src/GameEngine.cpp
      Each cell is DIJKSTRA_PASSABLE (0) or DIJKSTRA_BLOCKED (1).
      Blocked cells are never entered (infinite cost / skipped).

      Tile type          │ Fireboy grid │ Watergirl grid │ Step cost if passable
      ───────────────────┼──────────────┼────────────────┼──────────────────────
      TILE_EMPTY    (0)  │  PASSABLE    │  PASSABLE      │  1.0 (see B below)
      TILE_SOLID    (1)  │  BLOCKED     │  BLOCKED       │  —
      TILE_LAVA     (2)  │  PASSABLE    │  BLOCKED       │  1.0
      TILE_WATER    (3)  │  BLOCKED     │  PASSABLE      │  1.0
      TILE_POISON   (4)  │  BLOCKED     │  BLOCKED       │  —
      TILE_CONVEYOR_R(5) │  BLOCKED     │  BLOCKED       │  —
      TILE_CONVEYOR_L(6) │  BLOCKED     │  BLOCKED       │  —
      Closed gate        │  BLOCKED     │  BLOCKED       │  — (overlaid as SOLID)

  (B) EDGE WEIGHTS — DSA::dijkstraGridFind()
      Location : src/DSA.cpp
      Constants in include/GameObjects.h:

      • DIJKSTRA_STEP_COST     = 1.0f  — each cardinal move (N/S/E/W) to a
                                         passable neighbour
      • DIJKSTRA_TELEPORT_COST = 0.0f  — warp from pad tile to partner tile
      • DIJKSTRA_UNREACHABLE   = 1e9f  — initial distance before relaxation

      All passable tiles share the SAME step cost (1.0). There is no heavier
      weight for lava, water, or empty — only blocked vs walkable matters.

  (C) TELEPORT EDGES — GameEngine::buildEffectiveTileMap()
      teleportEdges[row][col] = partner column/row, or (-1,-1) if none.
      When stepping onto a pad, Dijkstra may relax the partner at cost +0.

  (D) OUTPUT — PathResult.len
      Total path cost = sum of edge weights ≈ number of tile steps (teleports
      add 0). Used by computeHints() and gemMinHeapFind() for nearest gem.

  Call chain : buildEffectiveTileMap() → buildGrid() → dijkstraGridFind()
               (hints: computeHints)   (nearest gem arrow: gemMinHeapFind)
